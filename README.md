# 🎮 AI Rock Paper Scissors (Python)

## 📌 Overview

This project is a smart implementation of the classic Rock-Paper-Scissors game using Python.
Unlike traditional versions, this game uses a simple AI strategy based on probability to predict the user's next move.

---

## 🧠 Features

* 🎯 AI-based move prediction
* 📊 Learns from user history
* ⚖️ Weighted probability decision making
* 🔁 Continuous gameplay with score tracking

---

## ⚙️ How It Works

1. The game stores user choices in a history list
2. It calculates the probability of each move (rock, paper, scissors)
3. Predicts the user's next move using weighted random selection
4. Chooses the best counter move

---

## 🚀 Technologies Used

* Python
* Random module
